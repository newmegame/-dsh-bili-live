# B站直播助手（DSH 插件）

在 DeepSeek Harness 的 Web 界面里加一个「B站直播助手」面板：连到指定直播间的弹幕流，按关键词规则或 AI 生成回复，扫码登录后以你的 B 站账号发出弹幕。

- 安装：见 [安装说明.md](安装说明.md)
- 发布到 GitHub / npm、收录进 DSH 社区：见 [PUBLISH.md](PUBLISH.md)

## 能做什么

- 监听任意 B 站直播间的实时弹幕（只读，匿名即可）。
- 关键词规则回复，支持 `{user}`、`{text}` 占位符。
- 命中不了规则时调用当前 DSH 默认模型生成不超过 20 字的回复。
- B 站扫码登录，凭据只保存在本机；登录后可手动发弹幕、补发预演结果。
- 限频保护：全局冷却、每分钟上限、同一用户冷却、重复内容去重、跳过命令式弹幕。
- 默认 **预演模式**：只生成和记录回复，不真正发送。关掉后回复会直接发出。
- 内置 `bili_live_status` / `bili_live_send` 两个工具：可以直接让助手读状态或发一条弹幕。
- 点歌：弹幕出现「点歌 歌名」这类内容时搜索网易云，直接播放所点歌曲（检测到客户端就唤起客户端，没有则开网页播放器）。

## 打开方式

安装后刷新 DSH 页面，左侧栏会出现「B站直播助手」图标（在「定时任务」和「技能」之间），点开就是面板。

## 使用步骤

1. 在「直播间」填入房间号（浏览器地址栏 `live.bilibili.com/` 后面的数字），点「连接直播间」。
2. 在「B站账号」点「扫码登录」，用哔哩哔哩手机客户端扫码并确认。
   扫码不方便时，同一张卡片里有「手动填 Cookie」：从浏览器 Cookie 里复制 `SESSDATA`、`bili_jct`、`DedeUserID` 填入即可。
3. 保持「预演模式」开启，观察「回复记录」里生成的话术是否合适。
4. 调整规则 / 冷却 / AI 开关后，关闭「预演模式」即开始真实发送。

关掉预演后，助手生成的回复会直接发到直播间，不再停在「待补发」。也可以直接对助手下指令发送，例如让它调用 `bili_live_send` 发一条不超过 20 字的弹幕（仍会检查登录、连接、违禁词和发送间隔）。

## 风险与边界

- 自动发弹幕走的是 B 站网页接口，属于非官方用法；频率过高可能被限流、禁言或限制账号功能。默认 12 秒冷却、每分钟 5 条，建议先用自己的小号或冷门房间验证。
- 平台可能随时调整接口或风控策略；发送失败时面板会显示服务端返回的错误码和信息。
- 本插件不绕过任何平台限制，也不支持多账号、抽奖、关注等操作。

## 点歌

开启后，弹幕命中触发词（默认「点歌 / 点一首 / 来一首 / 来首 / 放一首 / 放首 / 播放 / 想听」）就把后面的文字当歌名，去网易云搜索第一条结果并播放：

- 装了网易云客户端（`cloudmusic.exe`）时走 `orpheus://song/<id>` 协议直接播放；没装则打开网页播放器。
- 只把数字歌曲 id 交给系统，观众打的字不会进入命令行。
- 命中点歌的弹幕不再走聊天回复；点播成功后可按设置回一条「《歌名》开播啦」。
- 默认冷却：全局 15 秒、同一用户 2 分钟；自己账号的弹幕会被忽略，避免播报弹幕反过来触发点歌。
- 面板上可以开关、改触发词与冷却，也能手动输入歌名点播，并查看最近的点歌记录。

## 违禁词

面板里的「违禁词」卡片，每行一个词（也可用逗号分隔），保存后立即生效，按不区分大小写的包含匹配：

- **弹幕命中**：不生成回复，弹幕仍在列表里，标红「违禁词」；
- **生成的回复命中**：不发送，回复记录里标为「拦截」；AI 回复会带上这些词重试一次，仍命中才丢弃；
- **手动发送命中**：直接拒绝并提示具体是哪个词。

## 回复风格

面板里的「回复风格」卡片内置 8 个性格词条：自然、元气、温柔、高冷、整活、甜妹、二次元、直球。点一下即可切换，当前词条的描述会拼进 AI 的系统提示词，并优先于默认语气。

「+ 添加词条」可以写自己的词条名称和风格描述，例如：

- 猫娘：每句话结尾加一个「喵」，语气软一点
- 榜一大哥：热情一点，称呼观众为哥，多夸两句

自定义词条会出现在同一排，可随时删除；同一时间只有一个风格生效，想叠加多种感觉就写进同一个词条描述里。

风格只影响 AI 生成的回复，关键词规则仍是固定话术，不受影响。

## 数据保存在哪

`%DSH_HOME%\bili-live\state.json`（默认 `C:\Users\<你>\.dsh\bili-live\state.json`），包含设置和登录凭据（SESSDATA / bili_jct / buvid3）。文件以 `0600` 权限写入，但 Windows 上仍建议确认该目录只有你的账户可读。退出登录会清除凭据。

## HTTP 接口（面板使用，也可脚本调用）

同源 `http://127.0.0.1:<端口>/bili-live`：

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/state` | 当前状态快照 |
| GET | `/events` | SSE 实时推送 |
| POST | `/settings` | 修改设置（需 `x-bili-live: 1`） |
| POST | `/connect` | 连接直播间 `{roomId}` |
| POST | `/disconnect` | 断开 |
| POST | `/login/start` | 生成扫码登录二维码 |
| POST | `/login/cancel` | 取消扫码 |
| POST | `/logout` | 退出登录 |
| POST | `/send` | 以当前账号发一条弹幕 `{text}` |
| POST | `/reply-now` | 补发某条预演回复 `{id}` |
| POST | `/song/play` | 手动点歌并播放 `{query}`（需 `x-bili-live: 1`） |

## 目录结构

```
index.js              Host 半：连接、登录、回复引擎、HTTP/SSE、bili_live_status / bili_live_send 工具
client.js             Web 面板与侧边栏图标（原生 React.createElement，无构建步骤）
lib/bili.js           B 站接口：WBI 签名、getDanmuInfo、弹幕协议、发送、扫码
lib/ws.js             无依赖 WebSocket 客户端（node:tls / node:net / RFC 6455 帧）
lib/song.js           网易云搜索与播放（fetch 搜索接口、orpheus 协议唤起客户端）
vendor/qrcode-generator.cjs  MIT，Kazuhiko Arase，二维码矩阵生成（Host 侧）
locale/{zh,en}.json   插件管理器的标题与描述
icon.svg              插件图标
```
